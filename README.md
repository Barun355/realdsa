# DSA

Personal implementations while learning data structures and algorithms.

Each numbered folder is one concept. Code lives in the folder. Notes go in that folder's `docs.md`.

## Status

Working through **graph representations**.

Done so far:

1. Unweighted adjacency list (directed and undirected)
2. Unweighted adjacency matrix (directed and undirected)

JavaScript is the main language. Adjacency list also has C++ versions (was just experimenting).
